# 模拟炒股小游戏（HTML 单页版）

一个纯前端的模拟炒股小游戏：随机波动更新股价、支持买入/卖出、持仓与交易记录展示。

## 功能
- 26 支股票的简易行情列表
- 每 5 秒更新一次股价（带涨跌幅）
- 买入/卖出（最少 100 股，100 股为单位）
- 资金、持仓市值、总资产、收益率实时计算
- 持仓列表与交易记录
- 一键重开（重置资金与持仓）

## 技术栈
- HTML + 原生 JavaScript
- [Tailwind CSS CDN](https://cdn.tailwindcss.com)（无需构建）
